# Бот кодов Torchlight: Infinite

Проверяет источники по расписанию (просим GitHub каждые 5 минут, но он запускает реже) и пишет новые коды в Discord через вебхук.

Источники: API сайта TLI Compendium, страница кодов PocketGamer, официальные новости игры в Steam.

- `bot.py` сам бот.
- `seen_codes.json` коды, которые уже отправлены или известны как старые. Чтобы бот снова отправил код, удали его отсюда.
- `.github/workflows/check-codes.yml` расписание запуска на GitHub Actions.

Новый код приходит двумя сообщениями: `@everyone` с карточкой (награда, как ввести, где найден) и сам код отдельной строкой, чтобы удобно копировать.

Сторож: если источник ломается 3 проверки подряд (ошибка или пустой список) или падает сам бот, приходит одно сообщение о поломке и одно о починке. Если падает весь запуск на GitHub, тоже приходит одно сообщение о падении и одно, когда запуски снова проходят. Сбои идут в секрет `DISCORD_ALERT_WEBHOOK`, а если его нет, то в канал кодов. Там же висит табличка статуса, которую бот правит при каждой проверке: если время последней проверки давнее, бот не запускается.

Проверить сообщение о сбое: Run workflow с галочкой "Тест: уронить запуск".

Репозиторий публичный, потому что на бесплатном плане GitHub не запускает расписание в приватных репозиториях. Чтобы GitHub не выключил расписание после 60 дней без изменений, бот раз в месяц обновляет поле `heartbeat` в `seen_codes.json`.

URL вебхука хранится в секрете репозитория `DISCORD_WEBHOOK` (Settings > Secrets and variables > Actions).
Ручной запуск: вкладка Actions > "Проверка кодов Torchlight" > Run workflow.
